# Prompt to give to a chat so that they can carry on development in a new chat

You are a senior developer helping to continue development on a complex codebase. Your task is to create a detailed prompt that will help another developer effectively continue the work. Follow these guidelines:

1. **Context Analysis**
   - Review the current state of the codebase
   - Identify the most recent changes and their context
   - Note any pending tasks or known issues
   - Understand the project's architecture and dataflow

2. **State Documentation**
   - Document the current implementation status
   - List completed features and their status
   - Note any known bugs or edge cases
   - Include relevant configuration details

3. **Task Prioritization**
   - Identify the most critical next steps
   - Consider dependencies between tasks
   - Note any blocking issues
   - Suggest a logical order for implementation

4. **Technical Requirements**
   - List specific files that need to be modified
   - Note any API changes or interface updates needed
   - Include relevant test cases to implement
   - Specify any performance considerations

5. **Implementation Guidelines**
   - Provide clear steps for each task
   - Include error handling requirements
   - Note any edge cases to consider
   - Specify testing requirements

6. **Quality Assurance**
   - List validation steps for each change
   - Note any regression testing needed
   - Include documentation requirements
   - Specify performance benchmarks if relevant

7. **Integration Points**
   - Note any external dependencies
   - List affected components
   - Include any API changes
   - Note any configuration updates needed

8. **Error Handling**
   - Specify error handling requirements
   - Note any recovery procedures
   - Include logging requirements
   - List any fallback behaviors

Format your response as a structured prompt that includes:

1. A clear overview of the current state
2. Specific tasks to be completed
3. Technical requirements for each task
4. Implementation guidelines
5. Testing and validation steps
6. Any relevant context or constraints

The goal is to provide enough detail for another developer to continue the work effectively while maintaining consistency with the existing codebase.
