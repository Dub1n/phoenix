# Debug View

debugger that reads the contents of the typescript files and runs them but with it's own function names and endpoints, takes the input and runs it through the different functions at its own pace one at a time, storing the output at each point to be displayed. Might need some way of displaying single/multiple values at each stage.

make section collapsible/expandable so it can be a "high-level" input - output, or a more low-level view at the different stages

have the code itself available to view in a popup/ctrl+click, and things like duration shown above/below the nodes

make it easily terminal/MCP accessible so that LLMs can do realtime stepwise debugging
