# Traceability Matrix

Orientation note: This matrix maps priority regulatory clauses and user needs to the QMS realignment aims, the enabling features, and the evidence required for the MVP. It uses the same aim numbering as `01-Aims-and-Objectives.md` so delivery teams can align their backlog items with compliance outcomes.

## Matrix Overview
